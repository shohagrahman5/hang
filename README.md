# CodeAlpha Hangman Game

A beginner-friendly, text-based Hangman game built with Python.

## Features
- Randomly selects one word from a list of five words.
- Lets the player guess one letter at a time.
- Allows a maximum of six incorrect guesses.
- Checks invalid and repeated guesses.
- Displays whether the player wins or loses.

## Requirements
- Python 3
- No external libraries are required.

## How to run
1. Open this folder in VS Code.
2. Open the VS Code terminal (`Terminal` > `New Terminal`).
3. Run:

   ```bash
   python main.py
   ```

   On some Windows installations, use `py main.py`.

## Concepts used
`random`, lists, strings, `while` loops, `if-else`, functions and input/output.
